# Changelog

## 1.2.0 Network Performance RC

- Сетевые режимы «Автоматически», «Только IPv4» и «IPv4 и IPv6». В автоматическом режиме ошибки IPv6 TCP по разным префиксам запускают сравнительную проверку IPv4 и IPv6 через текущий прокси. Временный отказ ограничен по времени и пересматривается по мере появления трафика.
- Для HTTP CONNECT и некоторых подтверждённых отказов SOCKS5 VPN отвечает локальным ICMP Port Unreachable. SOCKS5 UDP учитывает реальный ответ релея. Автоматическое управление QUIC учитывает ответы на распознанные Initial-пакеты UDP/443 отдельно для IPv4 и IPv6.
- DNS-кэш учитывает TTL и отрицательные DNS-ответы с SOA. Одинаковые параллельные запросы объединяются в пределах одной политики DoH.
- Исходящие сокеты привязываются к выбранной физической сети. DNS получает отдельные места из существующего лимита потоков. Буферы TCP и UDP переиспользуются.
- Настройки производительности, диагностика активного профиля, времена стадий в журнале и обезличенная выгрузка. Старые записи и настройки читаются после обновления.
